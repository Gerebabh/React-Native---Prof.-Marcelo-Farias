  # Estrutura do projeto Expo

  - `package.json`: registra os dados do projeto, seus scripts e suas dependências.
  - `package-lock.json`: fixa as versões exatas das dependências instaladas pelo npm.
  - `App.js`: contém o componente principal e a tela inicial da aplicação.
  - `app.json`: guarda as configurações do aplicativo Expo, como nome, ícone e versão.
  - `assets/`: armazena imagens, ícones, fontes e outros arquivos visuais.
  - `node_modules/`: contém as bibliotecas instaladas pelo npm e não deve ser editada manualmente.
  - `.gitignore`: indica os arquivos e pastas que o Git não deve versionar.
  - `.expo/`: guarda configurações e arquivos temporários gerados pelo Expo durante a execução.
